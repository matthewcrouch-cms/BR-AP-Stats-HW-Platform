# BR: AP Statistics Homework Platform

Student homework site for AP Statistics (sections 1A, 2A, 2B, 3B), built like the H. Math 1 platform.

- `index.html` – student site (pick class → tap name → 4-digit PIN)
- `teacher.html` – gradebook, question insights, schedule, roster & PINs, Canvas export, preview as student
- `img/` – graphs used in the questions

Answers are checked on the Supabase server (`aps_` functions). Answer keys and PINs are **not** stored in this repo.
